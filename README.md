# To run project:

- download `https://github.com/zillur01/wrong-way-vehicle-detection.git`
- copy `yolov5` folder from above project directory and add to this folder's directory in `backend/`  <- required to run detector and tracker
- run:

  ```powershell
  cd backend
  python -W ignore -m scripts.run_detection_tracking
  ```
